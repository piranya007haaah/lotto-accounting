# TMB and TB9 across all two-digit lottery groups

`AllLotteryExperiment` reads the paginated bulk two-digit dataset, runs each lottery/position independently in a worker, and displays every group including errors and insufficient-history reasons. Inputs invalidate results; cancellation terminates the worker; detail requests use an id to reject stale responses. Batch messages contain summaries only, and complete numbers/audit are calculated for the selected group. Result exports record formula, year, stake, payout and completeness policy.

TMB uses `analyzeTmb` unchanged: seven groups, 3–12-month windows, 40–60 numbers and six prior validation months. Both main and baseline sets are chosen before the test month. Existing detail charts, group comparisons and retrospective tables remain available.

TB9 preserves `tb9Fixed`, the 2023 history origin and nine-calendar-month frequency window. Extension to other lotteries/positions and different payouts is explicitly labeled experimental. Default observed-only mode requires real outcomes in each of the nine training months; unknown days are not cancellations. Optional strict mode checks the full history from 2023-01-01, recognizes explicit `xx` markers, and exempts the eight document cancellations **only for Lao Star upper two digits**. Other groups never inherit these dates. The original verified Lao Star tab and IndexedDB snapshot namespace are retained separately; no cross-lottery snapshots are saved into that namespace.

All dates stay indexed by calendar offset, and gaps remain in the source strings. Missing years, non-calendar datasets and empty training months are not silently repaired. TB9 ages count actual observed draws, matching the original; gaps can change both ages and selected numbers. Annual DD is measured relative to initial capital, matching the existing Lab metric.

Validation: `jiti scripts/lab-all-check.ts [source-json]` checks cancellation isolation, explicit holidays, missing years, stake/payout scaling, no-lookahead and original Lao Star/TMB parity. A supplied source snapshot with 270 groups through September 2026 produced 236 computable TMB groups and 260 computable observed-only TB9 groups for 2026. These are data-coverage counts, not evidence of predictive accuracy. Browser QA intercepts API reads with the existing source snapshot and does not write production data.
