# TMB v0.1 — ทดลองตามเสียงเจ้าของ

เพิ่มแท็บ “ทดลอง TMB” ใน `/formulas` ของแอป LINE เดิม สูตร TB9-Fixed v1.0 คงเดิม

คำขอจากเสียง: เทียบ Top/Mid/Bottom และกลุ่มผสม 7 แบบ กรอบ 3–12 เดือน ชุดคงที่เดือนละ 40–60 เลข ตัดเลขถี่ผิดปกติ เติมเลขหายไปนาน และตรวจความสม่ำเสมอข้ามเดือน/ปี

## กติกาที่เพิ่มเพื่อให้คำอธิบายคำนวณได้

ค่าเหล่านี้เป็นสมมติฐานทดลองของ v0.1 ไม่ใช่ตัวเลขที่เจ้าของระบุในเสียง และไม่ได้จูนหลังเห็นผล:

- เรียงความถี่มากไปน้อย เท่ากันเลขน้อยก่อน แบ่ง Top34 / Mid33 / Bottom33
- Top หยิบถี่มากก่อน; Mid เริ่มอันดับกลาง (อันดับ51แบบนับจาก1); Bottom ถี่น้อยก่อน เท่ากันเลขน้อยก่อน
- กลุ่มผสมสลับหยิบทีละเลขตามชื่อกลุ่ม หากไม่พอ40–60 เติมกลุ่มอื่นโดยสลับ Top/Mid/Bottom จึงต้องเรียกว่า “กลุ่มหลัก” ไม่ใช่ชุดที่เป็นสมาชิกกลุ่มเดียวทั้งหมด
- ตัดเลขความถี่มากกว่า P95 แบบ nearest rank ของความถี่100เลขในหน้าต่างฝึก
- อายุคือจำนวนงวดจริงหลังออกล่าสุด เกณฑ์อายุคือ P95 ของช่วงไม่ออกที่จบแล้วภายในหน้าต่างฝึก รวม100เลข ไม่มีช่วงจบแล้วจะไม่ใช้กฎเติม เลขไม่พบมีอายุเป็นเพียงขอบล่าง
- เติมเลขอายุเกินเกณฑ์ก่อน เรียงอายุมากก่อน/เลขน้อยก่อน แล้วเติมตามอันดับกลุ่มจนได้nเดิม ตัดถี่เกินมีสิทธิ์เหนือกฎเติม
- ช่วงไม่ออกที่คร่อมขอบหน้าต่างไม่มีข้อมูลครบ จึงไม่ใช้คำนวณ P95 เกณฑ์นี้อาจต่ำกว่าประวัติเต็ม ไม่ใช่ขีดจำกัดทางธรรมชาติ
- มี1470สูตร (7×10×21) เปรียบเทียบทั้งแบบเดิมและแบบตัด/เติม
- ทุกเดือนเลือกสูตรและnด้วยกำไรแบบตัด/เติมของ6เดือนก่อนหน้า แต่ละเดือนคัดเลือกสร้างชุดจากอดีตของเดือนนั้นเอง จากนั้นล็อกชุดทดสอบใหม่ทั้งเดือน
- เสมอกันเลือกnน้อยก่อน แล้วลำดับกลุ่มตามรายการ Top,Mid,Bottom,Top+Mid,Top+Bottom,Mid+Bottom,ทั้งสาม และกรอบน้อยก่อน
- เปรียบเทียบชุดเดิมด้วยกลุ่ม/กรอบ/nเดียวกัน เป็นการเปรียบเทียบแบบจับคู่ ไม่ใช่การค้นหาสูตรเดิมที่ดีที่สุดแยกต่างหาก
- ตาราง7กลุ่มเลือกกรอบ/nล่วงหน้าภายในแต่ละกลุ่ม ส่วนตารางTop10ท้ายหน้าเลือกจากปีทดสอบ จึงติดป้ายรู้ผลแล้วอย่างชัดเจน
- กำไร=เงินต่อเลข×(เรตจ่ายรวม×จำนวนถูก−n×งวด); ROI=กำไร/ต้นทุนรวม; DD=peak-to-trough เริ่ม0; streakนับเฉพาะงวดขาดทุน วันที่ไม่มีผลไม่ตัด streak
- อ่านเฉพาะdigits2, UTC calendar positions, ไม่ยุบวันหยุดก่อนแบ่งเดือน ถ้าปีขาด/เดือนฝึกว่างไม่จำลองเดือนนั้น วันไม่มีผลอาจเป็นวันหยุดหรือข้อมูลขาด ไม่แต่งเติมผล
