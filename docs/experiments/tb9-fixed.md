# ทดลอง TB9-Fixed v1.0

เพิ่มใน `/formulas` → ทดลอง TB9 ของเว็บที่เปิดผ่าน LINE โดยใช้ API ผลหวยและสิทธิ์ดูหน้าหวยเดิม เฉพาะหวยลาวสตาร์ สองบน ไม่มีการส่งข้อความหรือบันทึกยอดเงินจริง

ข้อกำหนดต้นฉบับอยู่ใน `tb9-fixed-spec.md` ตัวคำนวณ `src/lib/lottery/tb9-fixed.ts` ยึด Python ที่แนบมา: 9 เดือนปฏิทินเต็ม, Top 34 / Mid 33 / Bottom 33, ผูกอันดับเสมอด้วยเลขน้อยก่อน, นับ gap จากงวดจริงก่อนเดือนเป้าหมาย, ชุดคงที่ 45–67 ตัว, จ่ายรวม 100 เท่า

ประวัติเริ่ม 2023-01-01 ตามขอบเขตข้อมูลอ้างอิง ไม่ใช้ประวัติก่อนหน้านั้นแม้ฐานข้อมูลมีอยู่ วันงดยืนยัน 8 วันมาจากเอกสารเท่านั้น วันที่หายอื่นบล็อกการสร้างชุดเดือนถัดไป ตรวจสองบนเทียบท้ายสามบนทุกวันที่มีข้อมูลทั้งคู่ แสดงจำนวนที่ตรวจได้จริง

## ขอบเขต snapshot ทดลอง

IndexedDB เฉพาะเบราว์เซอร์ปัจจุบัน ใช้ `add` เท่านั้น ไม่มี update/delete ในแอป SHA256 ของ JSON canonical (history_start, วันงดยืนยัน, [วันที่,เลข] เรียงวันที่ ก่อนเดือนเป้าหมายเท่านั้น) เป็น data_version และส่วนหนึ่งของ revision_id เรียกซ้ำด้วยข้อมูลเดิมคืน snapshot/เวลาเดิม ข้อมูลแก้ไขเพิ่ม revision ใหม่ เลือกดู revision เดิมและดาวน์โหลด JSON พร้อม audit ได้

**ยังไม่ใช่คลังกลางหรือบัญชีผลถาวรบนเซิร์ฟเวอร์** ไม่ซิงก์ข้ามเครื่องและล้างข้อมูลเบราว์เซอร์แล้วหาย ผลรายงวดอ่านจาก API ปัจจุบันแยกจาก snapshot ชุดเลข ผลย้อนหลังระบุชัดว่าเป็นการคำนวณใหม่ ไม่อ้างว่าได้ล็อกชุดไว้ก่อนรู้ผล และไม่มีการเขียนเวลาย้อนหลัง
