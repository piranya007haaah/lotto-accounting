# ย้ายทุกอย่างมาอยู่ที่นี่ที่เดียว (Vercel + Supabase)

> เอกสารส่งต่อ — เปิด session ใหม่แล้วอ่านไฟล์นี้ก่อน จะรู้ว่าอยู่ตรงไหนและทำอะไรต่อ
> อัปเดตล่าสุด: 4 ก.ย. 2569 · **ห้ามใส่ค่า secret จริงลงไฟล์นี้**

## มติที่ตกลงกันไว้ (ก.ย. 2569)

แอปหวยเดิม (`piranya007haaah/lottery-app` · Streamlit) **จะถูกยุบ** — ทุกอย่างย้ายมาอยู่แอปนี้
ทีละหน้า จนกว่าจะครบแล้วปิดโปรเจกต์นั้นทิ้ง

```
เครื่องเจ้าของ (scrape ผลหวย) ──┐
                                 ├──► Supabase ◄──► แอปนี้ (Vercel)
Streamlit ── กำลังจะเลิกใช้ ─────┘                    ├ กรอกผลเอง
                                                       ├ พอร์ต
                                                       └ สูตร / สถิติ / สามตัว
```

- **ไม่ทำท่อถาวรจาก Streamlit อีกแล้ว** — ที่เคยคุยกันเรื่องตั้ง Streamlit Secrets
  (`snapshot_url` / `snapshot_secret`) เพื่อให้ปุ่มในหน้า 📝 ส่งข้อมูลให้อัตโนมัติ **ยกเลิก**
  เพราะจะแยกขาดจากกัน ⇒ ข้อมูลเข้ามาทาง **เครื่องเจ้าของยิงตรง** เท่านั้น
- SQLite (`data/lottery.db` ฝั่งโน้น) ลดสถานะเหลือแค่ **ไฟล์ทำงานของ scraper**
  (ตัวที่รู้ว่างวดไหนมีแล้ว จะได้เติมเฉพาะช่องว่าง) ไม่ใช่ "ฐานข้อมูล" อีกต่อไป
- ⚠️ **ยิงเข้า Supabase ผ่าน API ของแอปนี้** (`/api/lottery/datasets` + shared secret)
  **ไม่ใช่ต่อ Postgres ตรง** — จะได้ไม่ต้องเอา `SUPABASE_SERVICE_ROLE_KEY` (คีย์เปิดทั้ง DB)
  ไปวางไว้ในเครื่อง และมีตัวตรวจรูปแบบข้อมูล (zod) คั่นอยู่แล้ว

## ทำต่อจากตรงนี้ — เรียงตามลำดับ

### 1. ตั้ง secret ที่ Vercel (ยังไม่ได้ทำ)

https://vercel.com/racer4/lotto-accounting/settings/environment-variables

```
PORTFOLIO_SNAPSHOT_SECRET = <สุ่มเอง: openssl rand -hex 32>
```
ติ๊ก **Production** → Save → ไป **Deployments** → deployment บนสุด → ⋯ → **Redeploy**

> ⚠️ env ใหม่ **ไม่มีผลกับ deployment ที่ build ไปแล้ว** ต้อง redeploy เสมอ — พลาดบ่อยสุด

**ตรวจ:**
```bash
curl -i -X POST https://lotto-accounting.vercel.app/api/portfolio/snapshot \
  -H "Content-Type: application/json" -d '{}'
```
- **401** `secret ไม่ถูกต้อง` = ✅ ถูกต้อง (ไม่ได้ใส่ header ก็ต้องโดนปฏิเสธ)
- 503 `ยังไม่ได้ตั้ง…` = ยังไม่ redeploy

### 2. ย้ายข้อมูลขึ้น Supabase (ครั้งเดียว)

รันในเครื่องที่มีรีโป `lottery-app`:

```bash
cd lottery-app && git pull
export SNAPSHOT_URL="https://lotto-accounting.vercel.app/api/portfolio/snapshot"
export SNAPSHOT_SECRET="<ค่าเดียวกับข้อ 1>"

python3 scripts/sync_to_supabase.py --dry-run   # ควรขึ้น 1,182 entry · 135 หวย
python3 scripts/sync_to_supabase.py             # ส่งจริง ~5 ก้อน
python3 scripts/export_portfolio_snapshot.py --id 4 --post   # พอร์ต Racer
```

**ตรวจใน Supabase SQL Editor:**
```sql
select 'lottery_datasets' as ตาราง, count(*) from lottery_datasets
union all select 'lottery_payouts', count(*) from lottery_payouts
union all select 'portfolio_snapshots', count(*) from portfolio_snapshots;
```
ต้องได้ **1182 / 1 / 1**

## Secret อยู่ที่ไหน (อย่าใส่ค่าจริงในรีโป)

| ค่า | เก็บที่ | ใช้ทำอะไร |
|---|---|---|
| `PORTFOLIO_SNAPSHOT_SECRET` | Vercel env | ฝั่งรับ — ตรวจ header `x-snapshot-secret` |
| `SNAPSHOT_URL` / `SNAPSHOT_SECRET` | env ของเครื่องเจ้าของ | ฝั่งส่ง — สคริปต์ Python ใช้ |
| `SUPABASE_SERVICE_ROLE_KEY` | Vercel env **เท่านั้น** | ⚠️ ห้ามเอาออกจาก Vercel เด็ดขาด |
| `SUPABASE_ACCESS_TOKEN` / `SUPABASE_PROJECT_REF` | env ของ environment (สำหรับ MCP) | ให้ Claude ต่อ Supabase ตรงบัญชี |

## กติกาที่ต้องยกไปด้วยตอนย้ายหน้า (พลาดแล้วเงียบ)

รวมไว้ที่นี่เพราะเป็นสาเหตุของบั๊กที่มองไม่เห็นด้วยตา — รายละเอียดเต็มอยู่ใน
`CLAUDE.md` ของ `lottery-app`:

1. **index ของ sequence = วันปฏิทินนับจาก 1 ม.ค. ไม่ใช่ "งวดที่"** — วันหยุดกินที่ของมัน
   ⇒ ตัดเดือนต้อง "ปิดวันอื่นเป็น `--`" ห้ามตัดสตริงให้สั้นลง (วันที่จะเลื่อนทั้งเส้น)
2. **จัดอันดับ n_bet บน train เท่านั้น ห้ามใช้ test** (= hindsight ตัวเลขโป่งเกินจริง)
3. **งวดที่ไม่ได้แทง (n=0) ไม่นับเป็นงวดที่แพ้** ตอนคิด win rate / ROI
4. **สีเขียว-แดงของแอปนี้แยกไม่ออกด้วยตาบอดสี** (วัดแล้ว ΔE 5.2 deutan)
   ⇒ บาร์กำไรใช้ **ทิศทาง** (ขวา=กำไร ซ้าย=ขาดทุน) + เครื่องหมาย +/− เป็นตัวบอกความหมาย
5. **ตัวเลขที่ทั้งสองแอปโชว์ต้องตรงกันเป๊ะ** ตราบใดที่ Streamlit ยังอยู่ —
   `npx tsx scripts/formula-check.ts` คือตัวกัน (เทียบกับเฉลยจริงจาก Python 2,460 จุด)
   · เฉลยสร้างใหม่ได้ด้วย `python3 scripts/export_engine_fixture.py` ฝั่งโน้น
