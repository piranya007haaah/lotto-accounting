# เทียบกรอบเดือนในหน้า /formulas

แท็บ “เทียบกรอบเดือน” เปรียบเทียบหวย 2 ตัวทีละหวย/ตำแหน่ง ใช้ข้อมูลจาก API เดิมที่ตรวจสิทธิ์ canViewLottery แล้ว คำนวณใน Web Worker เพื่อให้หน้าจอยังตอบสนอง ไม่เปลี่ยนข้อมูลหรือสูตรเดิม

## วิธีเลือก

1. เลือกเดือนทดสอบ และจำนวนเดือนก่อนหน้าสำหรับคัดเลือก (1 / 3 / 6 / 12; ค่าเริ่มต้น 3)
2. ลองกรอบฝึก 1 เดือนขึ้นไปจนถึงเดือนแรกที่มีผลจริง ก่อนเริ่มช่วงคัดเลือก ทุกกรอบใช้ช่วงคัดเลือกเดียวกัน
3. ในแต่ละเดือนคัดเลือก สร้างเลขด้วยสูตรจาก k เดือนปฏิทินก่อนหน้า เลือก n=1..99 ด้วยกำไรบน train เหมือน engine เดิม แล้ววัดผลเดือนถัดมา เลื่อนกรอบทีละเดือน
4. รวมกำไรช่วงคัดเลือก เลือกสูตรกำไรสูงสุดของแต่ละกรอบ และเลือกกรอบกำไรสูงสุดตามที่ผู้ใช้ระบุ กำไรเสมอกันเลือกกรอบสั้นกว่า; สูตรเสมอใช้ลำดับ registry
5. ใช้สูตรที่ชนะสร้างเลขใหม่จาก k เดือนก่อนเดือนทดสอบ เลือก n บน train เท่านั้น แล้วรายงานกำไร/ROI ของเดือนทดสอบแยก ผลทดสอบไม่ใช้เลือกกรอบหรือสูตร

เลือกสูตรเฉพาะสูตรได้เพื่อเทียบทุกกรอบของสูตรนั้น ROI = กำไร / เงินหมุนรวม ไม่ใช่ค่าเฉลี่ย ROI รายเดือน ชุดเลขคงที่ภายในเดือนที่วัดผล แต่สร้างใหม่เมื่อเลื่อนเดือน กรอบนับเดือนปฏิทิน ไม่ใช่ 30 วันย้อนหลัง

เดือนคัดเลือกเป็นข้อมูลที่ใช้หาคำตอบ ไม่ใช่ผลทดสอบอิสระ การค้นหาหลายสูตร/กรอบอาจ overfit; เดือนทดสอบจึงแสดงแยกและไม่เรียงอันดับตามกำไรทดสอบ เดือนล่าสุดอาจยังไม่ครบ จอแสดงวันที่ผลสุดท้าย เดือนแรกของประวัติอาจมีผลไม่ครบเดือน ไม่มีการตีความว่าเงินจริงของผู้ใช้ควรลงตามกรอบที่เลือก

## ขอบเขตข้อมูล

รองรับ digits=2 และ is_date_sorted=true เท่านั้น แปลงวันที่ด้วย UTC รวม leap year วันหยุดยังใช้ช่องปฏิทินเดิมก่อนแยกเดือน ปีที่หายไปไม่แทนเป็นวันหยุด ข้ามกรอบที่ขาดข้อมูลฝึก และแจ้ง error ถ้าปีช่วงคัดเลือกหายหรือไม่มีงวดจริง ตัวเลือกจำนวนกรอบขึ้นกับข้อมูลก่อนช่วงคัดเลือก ไม่ใช่รวมเดือนทดสอบเข้าไปด้วย

## รายละเอียดที่กดดูได้

จากปุ่มกรอบเดือนหรือ “ดูที่มาของกรอบและสูตรที่เลือก” เปิดหน้ารายละเอียด เลือกดูได้ทุกสูตรรวมสูตรที่ไม่ชนะ พร้อมกำไรคัดเลือก/ทดสอบแยกกัน กดแต่ละเดือนเพื่อดู:

- ช่วงฝึกจริงและจำนวนงวด ระยะใช้ชุดเลขครั้งละ 1 เดือน กราฟและความเสี่ยง
- ผลรายวันตามปฏิทิน: ผลหวย ถูก/ไม่ถูก ต้นทุน เงินรางวัล กำไร สะสม และทุนหลังงวด กดวันที่ดูสมการ วันไม่มีผลคิดเงิน 0
- เลขครบ 100 ตัวเรียงตามสูตร ทำเครื่องหมายเลขที่ใช้แทง กดเลขดูวันที่เคยออกในข้อมูลฝึก
- อันดับจำนวนเลขทั้งหมด 1–99 บน train พร้อมกำไร กดแต่ละจำนวนเพื่อดูต้นทุน/เงินรางวัล/ชุดเลข
- เดือนข้อมูลฝึกทั้งหมด กดเดือนดูผลทุกวัน รวมช่องที่ไม่มีผล

ผลทดสอบของทุกสูตรสร้างหลังเลือกผู้ชนะแล้ว ไม่มีการใช้ผลทดสอบเปลี่ยนผู้ชนะ รายละเอียดข้อมูลฝึก/รายวันคำนวณเฉพาะเดือนที่เปิดดู ลดขนาดข้อมูลระหว่าง Worker และหน้าจอ หน้าต่างเริ่มแสดงจากด้านบนเมื่อเปลี่ยนสูตรหรือเดือน

เพิ่มการตรวจเป็น 1,135 assertions: รายงวดรวมเท่ากับยอดสรุป ต้นทุน/ถูก/กราฟตรงกัน เลขครบ 100 จำนวนเลขครบ 99 วันหยุดเป็นศูนย์ วันจริงตรง leap year และชุดเลขของทุกสูตรไม่เปลี่ยนเมื่อเปลี่ยนผลทดสอบ Browser QA กดครบ 5 สูตร ทั้งเดือนคัดเลือกและทดสอบ ตารางจำนวนเลข เลขและวันที่ต้นทาง เดือนฝึก ผลรายวัน และปุ่มกลับ

ยังใช้ชุดเลขครั้งละ 1 เดือนเหมือนเดิม รอบนี้เพิ่มการตรวจสอบรายละเอียด ไม่ได้เพิ่มการทดลองถือสูตร/ชุดเลขต่อเนื่องหลายเดือน
