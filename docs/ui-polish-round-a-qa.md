# UI polish — รอบ A

12 กันยายน 2569

## เปลี่ยนแปลง

- คงโทนสีเดิม เพิ่มความเข้มข้อความรองและขนาดรายละเอียดเป็นอย่างน้อย 12 px ใน JSX ที่ปรับ
- ปุ่มหลัก/แท็บ/ช่องกรอกมีพื้นที่แตะ 44–46 px และเปิดให้ซูมหน้าได้
- เมนูคอมเป็นแถบด้านข้าง; หน้าเทียบกรอบเดือนและหน้าบันทึกบัญชีใช้สองคอลัมน์
- พับการตั้งค่าเงินและตัวเลือกวิเคราะห์ พร้อมแสดงค่าปัจจุบันในหัวข้อ
- เพิ่มเส้นทาง กรอบ → สูตร → เดือน; กลับจากเดือนแล้วคืนตำแหน่งเลื่อน
- Modal มีชื่อสำหรับ screen reader, focus trap, Escape, คืนโฟกัส และพื้นที่ safe area

## หลักฐานตรวจ

- Production webpack build และ TypeScript ผ่าน
- Engine ไม่เปลี่ยน; formula 2,460 + rank 1,086 + walk-forward 14,580 + monthly-window 1,135 + portfolio 1,920 = 21,181 จุดผ่าน
- ตรวจ browser ด้วย local production build ผ่าน proxy fixture อ่านอย่างเดียว; ทุก /api ถูก mock และคำขอเขียนถูกปฏิเสธ
- Chrome 1440 px: สูตรรายปี/รายเดือน, เปิดรายละเอียด, บัญชีสองคอลัมน์; summary/history/sites เปิดได้และไม่ล้นแนวนอน
- In-app browser: สูตร 390 px, รายละเอียดเดือน 390 px, พอร์ตมีผลคำนวณ 360 px, สูตร 768 px; ไม่มี page overflow ในจุดที่วัด
- Modal: เริ่มโฟกัสปิด; Shift+Tab วนไปปุ่มท้ายภายใน dialog; Escape ปิดแล้วคืนโฟกัสปุ่มเปิด
- ย้อนจากเดือนทดสอบกลับสูตรคืน scrollTop 547 px ใน fixture ที่ทดสอบ
- ตรวจภาพหน้าสูตร บัญชี พอร์ต และรายละเอียดเดือนในธีมสว่าง

## ขอบเขตที่ยังไม่ยืนยัน

- ไม่ได้ตรวจบัญชีจริงหลัง LINE Login: auto-review เคยปฏิเสธการเข้า OAuth; ใช้ fixture แทนโดยไม่ข้ามข้อจำกัด
- ยังไม่ได้ตรวจภาพธีมมืดหรือแป้นพิมพ์จริงบน iOS/Android
- ไม่ได้ทดสอบการส่ง LINE, OCR, หรือเขียนข้อมูลจริงในรอบนี้
- รอบ B–D ในแผนยังไม่เริ่ม; รอบนี้ไม่มี presets, การเทียบ 2–4 แบบ, รอบถือสูตรใหม่ หรือประวัติแผน
